# jules-playground — agent rules

Sandbox repo for testing Jules on self-contained web builds. Each test lives in
its own directory.

## Rules for every session

- Pure static output unless the brief says otherwise: HTML/CSS/JS, no npm, no
  build step, no compiled framework.
- One test per session. Work ONLY inside your assigned directory — never touch
  other tests' files.
- Read the brief in `briefs/` and every style doc it points to BEFORE writing
  code. The style docs are the quality bar.
- Verify visually: screenshot your pages in a headless browser and iterate until
  they are genuinely good. A finished build is not acceptance — beauty is.
- Commit and push to your branch after each milestone. Do not accumulate
  unpushed work.
- Do not ask clarifying questions — make the least-surprising choice and note it
  in your summary.
